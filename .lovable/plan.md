## Goal
Add a "Bulk Add" feature to Item List so the user can add many catalog items at once via Excel/CSV paste or file upload.

## Approach
Add a "Bulk Add" button next to "Add Item" on `src/pages/ItemList.tsx` that opens a dialog with two ways to import:

1. **Paste from Excel** (primary, fastest) — a textarea where the user pastes rows copied from Excel. Columns are tab- or comma-separated in this order:
   `Description | Item Code | UOM`
   - Description is required.
   - Item Code optional (auto-generated by existing `useCreateCatalogItem` hook when empty).
   - UOM optional, defaults to `pcs`.
2. **Upload .xlsx / .csv file** — uses `xlsx` (already in deps via `monthlyReportExcel.ts`) to read the first sheet and map the same three columns. First row treated as header if it contains "description"/"item code"/"uom" keywords; otherwise treated as data.

### Preview + validate step
After parsing, show a small preview table inside the dialog with:
- Row #, Description, Item Code, UOM, Status
- Status badges: `Ready`, `Duplicate (skip)` (when description+itemCode already exists in catalog), `Invalid` (missing description)
- Counts: `X ready · Y duplicates · Z invalid`
- Buttons: `Cancel` and `Import X items`

### Import execution
- Use sequential async processing (per project memory: bulk ingestion must be sequential, no parallel) — loop `await create.mutateAsync(...)` for each Ready row.
- Show progress: `Importing 5 / 20…`
- On finish: toast `Added N items` (and `Skipped M` if any), close dialog, list refreshes via React Query invalidation in the existing hook.

### Template helper
Add a "Download template" link in the dialog that generates a 1-row .xlsx with headers `Description, Item Code, UOM` so the user has the correct format.

## Files
- Edit `src/pages/ItemList.tsx` — add Bulk Add button + state.
- New `src/components/items/BulkAddItemsDialog.tsx` — the dialog (parse, preview, sequential import, template download).

## Out of scope
No schema changes. No changes to Requests, Trim Chart, or Delivery Notes. Existing single Add Item flow stays untouched.
